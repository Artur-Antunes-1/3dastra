Before you begin
Good questions.
Clear answers.
The skill organizes the process.
You still choose the direction.

      
What is a skill for AI agents?
A skill is a package of instructions and resources an agent reads to carry out a kind of work. 3DASTRA provides a visual-production workflow, prompts, comparison criteria, and an image-inspection utility.

      
Do I have to generate new images first?
If you already have a chosen image, the agent can start from it. Generate additional images to resolve style, shape, or material decisions that are still open. A small technical correction does not need to restart the entire process.

      
Does an image automatically become a 3D mesh?
The image guides construction. The agent uses available modeling tools to create geometry, materials, and exports. The skill asks it to reconcile views, verify physical contacts, and check the appearance in the final renderer.

      
Do I need Blender or a particular art style?
The workflow can be used with different modelers and renderers. Painted, stylized, and realistic approaches can follow the same process. Your agent needs access to the tools appropriate for the deliverable.

      
What tools does my agent need?
For the complete workflow, it needs to generate or receive images, work with a modeler, and capture the destination renderer. Interactive work also needs performance measurement. The optional image utility requires Python 3 and Pillow and does not modify inspected images.

      
Does 3DASTRA guarantee 60 FPS or a perfect match?
Performance depends on content, implementation, and hardware. The skill guides actual measurements and changes that preserve the visual target. Fidelity is assessed through captures and observed differences rather than a universal promise of identical reproduction.

      
Can I use it on an existing project?
Yes. Specify what must remain and what you want to refine. The agent reuses the approved direction, works on the affected stage, and checks for regressions in appearance and interaction.

      
Can I use and adapt the skill?
Yes. The skill and code are available under the MIT license in the public repository. The downloadable package includes the license. Showcase images have separate usage terms and are not included in the skill package.
