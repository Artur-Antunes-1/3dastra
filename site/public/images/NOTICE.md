# Showcase images

The images in this directory are demonstration and promotional materials.
They are not part of the reusable skill and are excluded from the repository's
MIT license. That license does not grant additional rights in these visual
assets. The Outfit font has its own license in the adjacent fonts directory.

The downloadable skill contains instructions, references, a template, an image
inspection utility, metadata, and its MIT license. It does not contain these
showcase images or any 3D project data.
